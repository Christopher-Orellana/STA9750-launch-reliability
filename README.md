# Commercial vs. Government Rocket Launch Reliability

Team Rocket \| STA 9750 \| Baruch College \| Fall 2026

## Our question

From 2000-2025, how does launch reliability differ between commercial and government providers, and what factors help explain the difference?

Reliability means successful launches divided by all launches with a success, failure, or partial-failure outcome. Unresolved outcomes are excluded.

## Our plan

1.  Use the Launch Library 2 production API to download launches, agencies, and rocket configurations.
2.  Create one shared source table for each of those three datasets, then join them into shared launch tables.
3.  Keep available launch history through 2025 to calculate rocket experience, then use the 2000-2025 subset for our main comparisons.
4.  Agree as a team on outcome and provider classifications and check data quality.
5.  Each member uses the shared tables to answer their question, adds their code and Quarto analysis to their own folder, and contributes findings to the group summary.

This repository currently contains the scaffold. Download scripts, datasets, and analyses still need to be built. Verify real API responses before writing extraction code.
